# VMD Sharing

Visual merchandising deliverables shared for reference/review.
Open any file directly in a browser — each one is fully self-contained
(no assets to download, works offline), or view it live via GitHub Pages.

## Karina FW26 — pre-launch dashboard (all 13 stores)

| File | Live |
|---|---|
| `karina-prelaunch-dashboard.html` | [view](https://fnf-hongkong.github.io/VMD-sharing-/karina-prelaunch-dashboard.html) |

One combined dashboard, tabbed by store code (M01…MC3, 13 stores). Each
store's card carries 3 parts: Mannequin Outfit (MAIN/SUB/3RD hover-for-
SKU coordination sets, where submitted), VP Table Setting (a styling
table's hover-for-SKU hotspots, skipped for the 2 stores with no VP
table), and the APP WALL render itself with its zoning crop, reference
photo, and full SKU list by wall bay. Same self-contained/offline-first
page as everything else here — just one file, no assets to fetch.

## Karina FW26 — APP WALL setup pages (single-store)

| Store | File | Live |
|---|---|---|
| M02 · Times Square | `karina-m02-app-wall.html` | [view](https://fnf-hongkong.github.io/VMD-sharing-/karina-m02-app-wall.html) |
| M14 · New Town Plaza | `karina-m14-app-wall.html` | [view](https://fnf-hongkong.github.io/VMD-sharing-/karina-m14-app-wall.html) |

**M02 — 2-bay setup page.** The store's own populated APP WALL render
plus, on one page: the zoning crop (designated setup area on the floor
plan), the reference photo of the existing wall, and the full SKU list
broken out by wall bay and by zone (top hanging / bottom hanging /
accessories) with the hero piece flagged. Hover any piece on the wall
render for its SKU, name and product shot; click any row in the SKU
list for a large photo.

**M14 — 3-bay wall render.** The wall page on its own (hand-curated
garment arrangement, M14's exact carried SKUs). Hover any item for its
SKU/name/photo.
