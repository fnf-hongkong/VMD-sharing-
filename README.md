# VMD Sharing

Visual merchandising deliverables shared for reference/review.
Open any file directly in a browser — each one is fully self-contained
(no assets to download, works offline), or view it live via GitHub Pages.

## VMD Weekly Report — floor before/after by store

| File | Live |
|---|---|
| `vmd-weekly-report/index.html` | [view](https://fnf-hongkong.github.io/VMD-sharing-/vmd-weekly-report/) |

The rolling weekly report. Pick a week and a brand, then a store down the left.
Each store opens on its floor plan — numbered dots with a "what is where" list
naming the theme on every fixture — followed by the before/after photos zone by
zone. Clicking a line on the plan jumps to that zone. W46 covers M01 Hollywood
Plaza, M02 Time Square, M10 Isquare and M11 APM.

Unlike the other files here this one is a folder rather than a single page: the
photos sit beside index.html.

## Meow in Winter — store display guideline (EN + 繁體中文)

| File | Live |
|---|---|
| `meow-in-winter-display-guideline/index.html` | [view](https://fnf-hongkong.github.io/VMD-sharing-/meow-in-winter-display-guideline/) |

What a store does on the floor for the Meow in Winter promotion, in three
parts. **01 Table Setting** — the hexagon and round VP tables, each with a
numbered callout on every piece and its style code. **02 Floor Hangers** — the
rail layout with all nine down jackets (which face out, which hang side-on,
and which hanger tag goes on each), the nine tags themselves, and photographs
of the real cord showing how the knot is tied. **03 Entrance POP** — the
promotion artwork and where it goes. A pre-opening checklist closes the page.

Every line is written twice, English then Traditional Chinese; style codes and
product names stay in English. Self-contained like the rest — one file, no
assets to fetch.

## Karina FW26 — pre-launch dashboard (all 13 stores)

| File | Live |
|---|---|
| `karina-prelaunch-dashboard.html` | [view](https://fnf-hongkong.github.io/VMD-sharing-/karina-prelaunch-dashboard.html) |

One combined dashboard, tabbed by store code (M01…MC3, 13 stores). Each
store's card carries 3 parts: Mannequin Outfit (MAIN/SUB/3RD hover-for-
SKU coordination sets, where submitted), VP Table Setting (a styling
table's hover-for-SKU hotspots, skipped for the 2 stores with no VP
table), and the APP WALL render itself with its zoning crop, reference
photo, and full SKU list by wall bay. Same self-contained/offline-first
page as everything else here — just one file, no assets to fetch.
